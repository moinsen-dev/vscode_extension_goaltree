# Task: Tree View Implementation

## Description
Implement VS Code TreeDataProvider for displaying goal hierarchy in the sidebar. Create GoalTreeProvider and GoalTreeItem classes that render the tree structure with proper visual indicators for goal states, tasks, and progress.

## Acceptance Criteria
- [ ] GoalTreeProvider implements VS Code TreeDataProvider interface
- [ ] GoalTreeItem represents individual tree nodes with proper icons
- [ ] Tree view displays in VS Code sidebar under dedicated view container
- [ ] Visual indicators for goal states (planned/in-progress/blocked/completed)
- [ ] Hierarchical display with unlimited nesting levels
- [ ] Collapse/expand functionality for goal branches
- [ ] Progress indicators showing task completion percentages
- [ ] Context menus for tree items

## Technical Details
- Register tree view in package.json contributions
- Implement TreeDataProvider.getChildren() for hierarchy
- Use VS Code ThemeIcon or custom icons for states
- Handle tree refresh when data changes
- Support tree item selection and focus
- Implement proper tree item tooltips with goal details

## Dependencies
- [ ] Task 001: Extension infrastructure for VS Code API
- [ ] Task 002: Data models for tree data source

## Effort Estimate
- Size: L
- Hours: 16-20
- Parallel: false (depends on both 001 and 002)

## Definition of Done
- [ ] Tree view appears in VS Code sidebar
- [ ] All goal states render with distinct visual indicators
- [ ] Tree hierarchy accurately reflects goal parent-child relationships
- [ ] Tree updates automatically when data changes
- [ ] Context menus provide access to goal operations
- [ ] Performance acceptable for 100+ goals
