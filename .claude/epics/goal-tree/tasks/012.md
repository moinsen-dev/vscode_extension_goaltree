# Task: Data Models and Storage Service

## Description
Implement core data models (Goal, Task, GoalTree) with TypeScript interfaces and create the JSON-based storage service with workspace isolation. This provides the data foundation for all goal management operations.

## Acceptance Criteria
- [ ] Goal interface with all required fields and status enum
- [ ] Task interface with status and ordering fields
- [ ] GoalTree container class for hierarchy management
- [ ] StorageService class with workspace isolation
- [ ] JSON schema validation for data integrity
- [ ] Auto-save functionality on data changes
- [ ] Error recovery for corrupted data files
- [ ] Backup/restore capabilities

## Technical Details
- Implement interfaces in src/models/ directory
- StorageService uses workspace storage location (.vscode/goal-tree.json)
- Include schema validation using TypeScript type guards
- Implement change notifications using VS Code EventEmitter
- Handle concurrent access protection
- Provide data migration strategy for schema changes
