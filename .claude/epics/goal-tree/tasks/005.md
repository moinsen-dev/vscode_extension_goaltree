# Task: Dependency Management

## Description
Implement goal blocking relationships and dependency management. Create DependencyResolver service to handle "blocked by" relationships between goals, circular dependency detection, and automatic unblocking when dependencies complete.

## Acceptance Criteria
- [ ] Goals can be marked as "blocked by" other goals
- [ ] Visual indicators in tree view show blocking relationships
- [ ] Circular dependency detection prevents invalid relationships
- [ ] Auto-unblocking when blocking goals are completed
- [ ] Dependency chain visualization (show path to unblocking)
- [ ] Bulk dependency operations (block multiple goals by one)
- [ ] Dependency validation during goal operations
- [ ] Clear dependency removal when goals are deleted

## Technical Details
- Create DependencyResolver service in src/services/
- Implement graph algorithms for circular dependency detection
- Add visual indicators (icons, colors) for blocked goals in tree view
- Validate dependencies during goal status changes
- Provide dependency chain analysis for blocked goals
- Handle dependency cleanup during goal deletion
