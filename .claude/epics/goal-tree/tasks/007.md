# Task: Task Management System

## Description
Implement task operations within goals including creation, completion tracking, reordering, and progress calculation. Tasks are sub-items within goals that provide granular progress tracking and actionable work items.

## Acceptance Criteria
- [ ] Task creation within any goal with title and description
- [ ] Task status management (todo → in-progress → done)
- [ ] Task reordering with drag-and-drop or move commands
- [ ] Task deletion with confirmation
- [ ] Progress calculation based on completed tasks
- [ ] Task completion automatically updates parent goal progress
- [ ] Task editing for title and description changes
- [ ] Task filtering and sorting options

## Technical Details
- Extend GoalManager or create separate TaskManager service
- Implement task ordering with numeric order field
- Calculate goal progress as completed tasks / total tasks
- Update tree view to show task progress indicators
- Handle task state transitions with validation
- Support bulk task operations (mark multiple done)

## Dependencies
- [ ] Task 002: Data models for Task interface
- [ ] Task 004: Goal management system for integration

## Effort Estimate
- Size: M
- Hours: 14-18
- Parallel: true (after dependencies)

## Definition of Done
- [ ] All task operations implemented and working
- [ ] Task progress correctly updates parent goal status
- [ ] Task reordering works through UI interaction
- [ ] Task completion provides visual feedback
- [ ] Progress calculations are accurate and performant
- [ ] Task operations integrate with tree view display
- [ ] Bulk operations support efficient task management
